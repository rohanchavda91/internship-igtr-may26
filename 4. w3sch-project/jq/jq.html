jQuery Tutorial

jQuery is a fast, small, and feature-rich JavaScript library. It makes things like HTML document traversal and manipulation, event handling, animation, and AJAX much simpler.

Learning by Examples

With our "Try it Yourself" editor, you can edit the jQuery code and see the result directly in the browser:

Example

$(document) . ready ( function () {
   $ ( "#demo" ) . click ( function () {
     $ ( this ) . hide ();
   });
});

Learn jQuery

Start with selectors and events, then learn effects, HTML and CSS manipulation, DOM traversal, AJAX, JSON, forms, plugins, callbacks, chaining, iteration, utilities, promises, and advanced jQuery techniques.
