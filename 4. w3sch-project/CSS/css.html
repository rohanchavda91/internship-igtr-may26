CSS Tutorial

CSS is the language we use to style an HTML document. CSS describes how HTML elements should be displayed on screen, on paper, or in other media.

Example

  background-color: lightblue;
}

h1 {
  color: navy;
  margin-left: 20px;
}

p {
  font-size: 18px;
}
